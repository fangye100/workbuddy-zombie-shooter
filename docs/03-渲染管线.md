# L3 — 渲染管线设计

## 1. 选型：Clustered Forward+

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 传统 Forward | 简单、MSAA 友好、材质灵活 | 光源数受限 | 不够 |
| **Clustered Forward+** | 光源 O(千) 级、MSAA 可用、材质分支自由、无 GBuffer 带宽 | 需要一次 compute 分簇 | **采用** |
| Deferred / GBuffer | 光照与几何解耦 | WebGPU 带宽吃紧，透明与 MSAA 难，材质变体受限 | 作为 Debug/备选 |
| Visibility Buffer | 极致去 overdraw | 材质需全 deferred 化，工程复杂度极高 | 远期研究 |

**Cluster 划分**：屏幕 16×16 tile（按动态分辨率缩放），深度方向 **指数切片** 24 层
（`zSlice = floor(log2(z/near) * scale)`），近处密、远处疏。数据源为深度缓冲。

分簇 compute 流程：
1. 清 cluster grid 计数（fill 0）
2. 每 cluster 求 AABB（用深度 min/max，从 depth reduce 得到）
3. 光源 vs AABB 相交测试（点光=球，聚光=锥，用 cone-sphere 近似）
4. prefix sum 分配偏移 → 写入 light index list（compact）
5. 输出：`ClusterGrid(uint2 offset,count)` + `LightIndexList(uint)`

> 用 `subgroups`（T2）时第 3 步可用 subgroup ballot 大幅加速；无则退化为每线程遍历光源。

## 2. 一帧 Pass 拓扑

```
                     ┌──────────── 上一帧 HiZ（延迟 1 帧）────────────┐
                     ▼                                                │
[1] Async: HiZ 重建 ──┐                                               │
[2] Compute 剔除 ─────┤ (frustum → HiZ occlusion → meshlet → sort)    │
[3] Skinning (compute)┤ → BoneMatrix SoA                              │
[4] Particle simulate ┘ → indirect args                               │
                     │                                                │
[5] Shadow Pass ─────┤ CSM 4 级 + Spot atlas + Point (双抛物面/立方)  │
                     │    indirect draw，reverse-Z，无 pixel shader   │
[6] Depth Prepass ───┤ 可选（Forward+ 下为 HiZ/AO/SSR 提供深度）      │
[7] Cluster 分簇 ────┤ compute，读 [6] 深度                           │
[8] Opaque ──────────┤ Clustered Forward+ 主光栅，MRT 或单 RT         │
[9] Decal ───────────┤ 贴花（clustered decal 或 deferred-like 投影）  │
[10] Sky/Atmosphere ─┤ 程序化天空 + 体积雾（froxel）                   │
[11] AO (GTAO) ──────┤ 半分辨率 + 时域累积                            │
[12] SSR / SSGI ─────┤ 半分辨率 HiZ trace +  reprojection             │
[13] Lighting 合成 ──┤ IBL + probe + SSR 反射 + AO 合成               │
[14] Transparent ────┤ weighted-blended OIT 或排序前向                │
[15] Post ───────────┤ TAA/TAAU → Bloom → Tonemap → Grading → Sharpen │
[16] UI / Debug ─────┘ 独立 render pass，sRGB，预乘 alpha
```

**Pass 全部注册为 `RenderFeature`**，由 `RenderPipeline` 按配置装配，支持裁剪：
2D 项目可以只装配 `[8 Opaque, 16 UI]`。

```ts
interface RenderFeature {
  readonly name: string;
  setup(deps: FeatureDeps): void;        // 声明要读写的资源
  execute(ctx: RenderContext): void;     // 往 graph 里 addPass
  readonly minTier: CapabilityTier;      // 能力不足时整块跳过
}
```

## 3. 各阶段要点

### 3.1 阴影

| 类型 | 方案 |
|---|---|
| 方向光 | **CSM 4 级**，指数分布 + 稳定化（snap to texel，`shadow texel snapping`），atlas 2×2 |
| 聚光 | 单张 atlas slice，透视投影 |
| 点光 | **双抛物面**（比 cubemap 少 6 个 pass）或 cube array（T1 起支持） |
| 过滤 | PCF 5×5 + **级联间混合**；可选 PCSS 软阴影（按距离） |
| 缓存 | 静态物体阴影走 **cached shadow**（仅当光源/物体移动时重画），大幅省算力 |

反向 Z + `depthCompare:'greater'` 贯穿；阴影 pass 用 **depth-only pipeline**（无 fragment
shader，或空 fragment），带宽最省。

### 3.2 GI 与环境

- **远场**：Light Probe 网格（运行时或烘焙），三线性插值 + **SH9**（9 系数 × RGB）。
  差分更新：只重算变动区域的 probe。
- **中/近场**：**SSR**（HiZ trace，半分辨率，时域重投影累积）；
  无命中处回退到 **Reflection Probe**（按体积混合 + 视差校正 box projection）。
- **可选 DDGI**：probe grid + ray-casting compute（T2 起启用），用于动态 GI。
- **AO**：GTAO（比 SSAO 质量高、成本相近），半分辨率 + 双边上采样 + 时域累积。

### 3.3 材质与 PBR

- BRDF：**Cook-Torrance**，GGX NDF + Smith height-correlated visibility + 多散射补偿
  （`multiscatter` 近似，避免能量损失导致的暗化）。
- 通道打包：`albedo.rgb` + `ORM`（AO/Roughness/Metallic 三合一）+ 法线（XY 或 octahedral
  编码 RGBA8）+ emissive。目标每材质 **3 张纹理**（BC7/BC5 压缩）。
- 变体：`SKINNED / ALPHA_TEST / ALPHA_BLEND / DOUBLE_SIDED / EMISSIVE / CLEARCOAT`。
- **材质实例**：uniform 覆盖（不改 shader），支持 `MaterialPropertyBlock` per-instance。

### 3.4 透明与后处理

- **透明**：默认 depth-sorted 前向（正确但慢）；可选 **weighted-blended OIT**
  （两次 pass：累积 + 合成，无序无关，适合烟雾/粒子）。
- **TAA**：Halton(2,3) 抖动 + 运动向量 + 邻域裁剪（variance clipping）+ 历史拒绝。
  **与反向 Z 配合时注意**：深度比较要用 linear depth。
- **TAAU**：渲染分辨率 0.5–1.0× 动态，TAA 阶段上采样。低端设备主要性能来源。
- **Tonemap**：**AgX**（高光去色更自然）为主，ACES 备选；后接 color grading LUT（3D LUT 16³）。
- **Bloom**：6 级 mip 下/上采样（Karis 平均防闪烁），阈值 + soft knee。
- **DOF / Motion Blur / Chromatic Aberration / Vignette / Film Grain**：按需开关。

### 3.5 天空与雾

- 程序化大气：单次散射近似（Rayleigh + Mie），LUT 化（transmittance + multi-scatter）。
- **体积雾**：froxel 网格（160×90×64），compute 注入散射 + 光照 → 时域累积 → 前向应用。
- 高度雾 + 局部雾体积（box/sphere）。

## 4. 渲染与逻辑的解耦（RenderWorld）

```
World (逻辑 ECS)                 RenderWorld (渲染快照)
 ├─ Entity + 组件 SoA    extract  ├─ RenderObject[]  (SoA: meshId, materialId, ...)
 ├─ 可被任意系统修改     ──────▶  ├─ TransformSoA    (model, prevModel, normalMat)
 ├─ 帧内可继续演进                 ├─ LightSoA / CameraData / SkinData
                                  └─ 只读，ring 池 3 帧轮转，GPU 读完后复用
```

- `extract` 阶段用 **并行 Job** 从 World 复制/映射数据；零分配（预分配 SoA + 长度游标）。
- 渲染层**永不回写**逻辑层，保证物理/网络回滚时渲染状态可重放。
- 变更检测：组件带 `ChangedTicks`，脏标记驱动增量更新（避免全量拷贝）。

## 5. 渲染排序与合批

排序键（64 位，从高到低）：
```
[ 3b queue ] [ 8b pass/layer ] [ 16b materialId ] [ 12b depth(前向) ] [ 20b meshId ] [ 5b variant ]
```
- **不透明**：按 materialId 分组 → 组内按深度**前向后**（配合 depth prepass）。
- **透明**：按深度**后向前**。
- **合批**：GPU instancing（同 mesh 同材质，instance data 走 storage + `instance_index`）；
  小物体走 **auto-instancing**（剔除后按 mesh+material 分桶，自动生成 instance 列表）。

## 6. 调试视图与验证

- **帧捕获对比**：`tools/trace` 抓取 pass 序列 + 资源声明，输出 JSON，
  CI 里做 **管线回归对比**（防止"改了一行，多了两个 pass"）。
- **Golden image**：固定相机 + 固定 seed，逐帧比对缩略图哈希，误差阈值内放行。
- **Validation 模式**：所有 pass 强制 `storeOp='store'` + 全资源可采样，便于截图调试。
