# 13 · 末日尸潮 — 玩法与关卡设计 GDD

> 版本：v0.1 draft（设计基线，数值未 playtest，凡无验证路径者标 `[PLACEHOLDER]`）
> 前置条件（已与制作人锁定）：第三人称俯视 · mobile 横屏 · 美漫描边 · 短局 5–8 分 · 程序生成楼层 · rogue + 轻度元进度 · 目标用户=硬核 rogue

---

## 0. 设计张力（先摊开，不假装一致）

**短局 + 硬核 + 轻度元进度** 三者在直觉上打架：硬核意味着"死亡要有重量"，短局意味着"留不住人"，轻度元进度意味着"死亡惩罚要轻"。

**解法**：把"硬核感"的来源从 *长局沉浸* 改成 *build 深度 + 廉价重开 + 元进度稀释挫败*。
- 死亡重量 → 来自"本局 build 全丢" + "明明差一点"的遗憾，不来自"耗了 40 分钟"。
- 短局留存 → 来自"重开 < 10 秒" + "前 90 秒就有流派信号"。
- 轻度元进度 → 买的是**选项**（更多角色/武器基底/天赋池），不是**数值碾压**，保住硬核挑战。

对标验证过模型：*The Binding of Isaac* / *Enter the Gungeon*（短局 + 程序楼层 + 元解锁 + 硬核）。

---

## 1. Fun Hypothesis（一句话）

> 在 5–8 分钟的高压短局里，用随机掉落的 build 碎片拼出一套越打越爽的割草流派，然后被一个你舍不得退出的死亡终结——而那点挫败被"下次换个 build 就能过"的元进度稀释成"再来一局"。

**可证伪断言**：如果玩家首局后 24h 内不开第二局，或平均单局 < 2 分钟，hypothesis 不成立（见 §9 失败信号）。

---

## 2. Design Pillars（5 条不可妥协）

| # | 支柱 | 玩家体验标准 | 违反即否决的例子 |
|---|------|------------|----------------|
| P1 | **流派即身份** | 前 90 秒必须拿到第一个明确的 build 方向（元素/暴击/范围/召唤/机动） | 进局 2 分钟还在"随手捡枪"，无流派感 → 流失 |
| P2 | **死亡是逗号** | 单局死亡只丢本局 build，元货币保留，重开 < 10 秒 | 死亡要回主菜单 / 加载 > 10 秒 → 挫败堆积 |
| P3 | **割草密度** | 僵尸多、死脆、反馈炸（屏震/描边闪光/跳字） | "硬核=慢节奏"是错的；硬核≠慢 |
| P4 | **随机可读** | 程序楼层让玩家一眼看懂"这层在逼我做什么决策" | 纯随机瞎生成 → 玩家觉得"不公平"而非"有挑战" |
| P5 | **元进度买选项** | 元货币解锁角色/武器/天赋池，不直接变强碾压 | 元进度 = 数值碾压 → 硬核感崩塌，变 pay-to-win |

## 3. Core Loop（三层钩子）

### 3.1 Moment-to-Moment（0–30s）
进房 → 尸潮涌入 → 走位+射击 → 击杀爆掉落 → 捡到一件**改变流派**的装备/天赋 → 立刻变强反馈。
*每一拍都要有"动作→反馈→奖励"闭合，否则手感断。*

### 3.2 Session Loop（5–8 min）
选楼层入口 → 连过 3 层（战斗→事件→精英） → 层末商店/祭坛 → 第 3 层 BOSS → **死亡或通关** → 结算元货币 → 一键"再来一局"。

### 3.3 Long-term（hours–weeks）
元货币 → 解锁角色/武器基底/天赋池 → 更高难度楼层 → 赛季排行榜 → 图鉴收集。

## 4. 关卡结构（程序生成楼层）

### 4.1 单局骨架（短局约束 = 固定 3 层）
每层由「房间图」程序组合，但**带约束的加权随机**，不是纯随机（保 P4 可读性）。

| 层 | 模板（房间序列） | 意图 |
|----|----------------|------|
| 层 1 | 战斗 ×2 + 事件 ×1 | 教学+首流派信号，低密度 |
| 层 2 | 战斗 ×1 + 精英 ×1 + 事件 ×1 | 压力升级，首个精英掉高品质 |
| 层 3 | 精英前置 ×1 + **BOSS** | 高潮，死亡 or 通关 |

### 4.2 房间池（程序抽样的原子）
| 房间 | 行为 | 清场条件 | 产出 |
|------|------|---------|------|
| 战斗房 Combat | 固定刷一波僵尸 | 全清开门 | Scrap + 概率天赋 |
| 事件房 Event | 岔路决策 | 选完即走 | 高风险高回报（宝箱/陷阱/献血换 buff） |
| 精英房 Elite | 1 精英 + 小兵 | 精英死 | 高品质天赋/武器 |
| 商店/祭坛 Shop-Altar | 交互 | 主动离开 | 花 Scrap 买装备 / 献血换天赋 |
| 休息房 Rest | 交互 | 主动离开 | 回血 / 升级 1 个已有天赋（**硬核下稀缺**） |

### 4.3 楼层主题（让随机有语义 = P4 的关键）
进层前 UI 大字明示主题 + 描边 icon，逼玩家做"这层我该拿什么"的决策：

| 主题 | Hazard | 鼓励的 build |
|------|--------|-------------|
| 火场 Fire | 地面火池 | 机动 / 范围 |
| 尸潮 Swarm | 僵尸量 ×2 | AOE / 召唤 |
| 腐液 Corrosion | 酸雨持续掉血 | 吸血 / 护盾 |
| 暗巷 Dark | 视野缩小 | 照明 / 暴击 / 范围 |

### 4.4 难度曲线（数值，全部待 playtest）
- 战斗房僵尸数：层1 = 8–12，层2 = 14–20，层3 前置 = 10 + BOSS。`[PLACEHOLDER · 假设：根据 alpha 200 局采样调]`
- 缩放规则：僵尸血量/伤害随 `楼层深度 + 本局已击杀数` 轻微缩放，防 snowball 失控也防无聊。`[PLACEHOLDER · 缩放系数 k=待定]`
- BOSS 设计 3 个（对应 roster 里 B-01/B-02/B-03），各带 1 个**反 build** 机制（如 B-02 火免 → 逼换流派）。

## 5. 战斗 & Build 系统（硬核 depth 的来源）

### 5.1 武器基底（元解锁，每把 1 个固有特性）
手枪（稳定）/ 霰弹（近距爆发）/ 冲锋枪（弹幕）/ 狙（远程秒杀）/ 电锯（近战范围）/ 火焰喷射（持续元素）。

### 5.2 天赋（run 内掉落，3 选 1）
5 系：**元素**（火/电/毒）· **暴击** · **范围** · **机动** · **召唤**（炮塔/僵尸犬）。
- **Build 雪球**：同系可叠加（火×3 → 燃烧蔓延），形成流派 → 满足 P1。
- **硬核体现**：① 无/半自动瞄准（设置可关）；② 受击有硬直 + 弹药有限；③ 死亡丢全部 run build；④ 高难楼层怪物带反 build 机制。

### 5.3 流派成型反馈
集齐同系 3 个天赋 → 弹"流派成型"横幅 + 全屏描边闪光（美漫分镜感）。

## 6. 经济系统：Sources & Sinks

**两种货币，职责严格分离**：

| 货币 | 生命周期 | Source | Sink | 防通胀机制 |
|------|---------|--------|------|-----------|
| **Scrap 废料** | 局内，局末清零 | 击杀掉率 `[PLACEHOLDER]` + 事件奖励 + 层末结算加成 | 商店买装备 / 祭坛换天赋 / 休息房升级 | 局末清零 → 天然平衡，无累积通胀 |
| **Essence 尸髓** | 跨局保留 | 每层通关 +X `[PLACEHOLDER]` + BOSS 首杀 +Y + 里程碑（累计击杀/通关数） | 一次性解锁角色/武器/天赋池 | 解锁为一次性 sink，池子有限 → 无持续通胀 |

**已识别通胀风险**：Essence 全解锁后无处可花 → 必须准备**二级 sink**：外观/赛季积分/挑战模式。否则 meta 在 2 周内"通货膨胀死"。`[待验证：全解锁中位数时长]`

## 7. 上头杠杆（10 个具体机制，按成瘾原理排序）

| # | 机制 | 成瘾原理 | 落地要点 |
|---|------|---------|---------|
| 1 | 前 90 秒首流派信号 | 早期承诺效应 | 开局必掉 1 天赋，立刻改手感 |
| 2 | 可变比率掉落 | 斯金纳箱最优曲线 | 保底 + 随机，不是固定掉 |
| 3 | 近距离逃脱 near-miss | 风险多巴胺 | 贴脸反杀给慢动作 + 描边高亮 |
| 4 | 流派成型横幅 | 完成感 | 同系 ×3 全屏闪光 |
| 5 | 死亡高光回放 | 死的也爽 | 自动剪 3 秒最爽击杀，美漫分镜 |
| 6 | 重开 < 10 秒 | 降低重开摩擦 | 死亡界面直接"再来一局"，不回主菜单 |
| 7 | "差一点"提示 | 目标梯度 | 通关差一丝 → "再解锁 X 就能过" |
| 8 | 赛季/每日挑战 | 长期目标 | 硬核玩家排行榜 |
| 9 | 图鉴收集 | 收集癖 | 僵尸/武器图鉴 |
| 10 | 最深楼层纪录 | 社交炫耀 | 破纪录弹"新纪录"，可分享 |
