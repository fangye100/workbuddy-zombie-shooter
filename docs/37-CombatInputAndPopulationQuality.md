# 战斗密度、攻击节奏与游戏输入验收

2026-10-07。基于 `codex/scene-authoring-loop`，保留主分支已合入的 rigging / shared motion retargeting，不修改角色绑定、源模型或骨骼资产。

## 设计依据与交付

对照 [Ardot Gameplay](https://ardot.tencent.com/file/720788949675822?node_id=2%3A74) 的密集尸潮、横屏双摇杆和美漫攻击反馈，以及 `docs/13` 和 `assets/characters/roster.json` 的攻击描述。本次调整是可继续调参的玩法实现，不代表完整关卡平衡或所有美术设计已最终验收。

| 项目 | 实现 |
|---|---|
| 双语 | 游戏 HUD、内置目标、补给、天赋、结算即时中文/英文切换，单独保存语言偏好，不重载游戏或改编辑器语言；自定义作者文本没有翻译时保留原文 |
| NPC | 常规刷怪 ×3、swarm ×4；每层总量 72 / 137 / 53，首波 24 / 48 / 16；精英和 Boss 保持单体。仍走运行时实例批次，静态物件 57 / 55 / 56，不占用热实体数量 |
| 起手门禁 | 当前 NPC 与玩家距离必须小于其 `triggerRangeM ?? rangeM`，冷却结束且取得普通攻击令牌后才进入前摇；普通攻击令牌上限 4，单体精英/Boss 独立 |
| 状态节奏 | 各 NPC 独立种子流：感知/追击决策 0.08–0.35s、恢复 0.20–0.55s、前摇额外 0–15%、冷却额外 0–35%。自主状态转移错开；伤害、死亡等事实立即生效，不人为延迟命中 |
| 动作 | 前摇从各 NPC 自己的起手播放攻击动作，不再全体使用同一个循环相位；已有 idle/walk 的实例相位偏移保留。专用动作缺口见 docs/38 |
| 桌面 | WASD/方向键沿屏幕方向移动，鼠标独立瞄准，左键开火、R 换弹、E 交互、空格暂停；J 保留兼容，鼠标瞄准优先于辅助瞄准 |
| 手机界面 | 横屏左右独立指针捕获摇杆：移动、瞄准并射击；换弹/上下文交互按钮。触控或键鼠可切换，游戏视图隐藏编辑器面板 |
| 输入生命周期 | 松开、取消、失焦、页面隐藏、暂停、升级选择和终态清除移动/射击/手动瞄准，防止粘键 |

攻击参数真源是 `stats.json`，通过生成器生成类型化数据；NPC 时序和令牌额度是场景 `RunRules`。schema 11→12 有迁移和校验，12 个已登记场景同步升级；关卡生成器保留玩家、动作与相机配置。存量小规模调度回归测试使用独立小规模夹具，避免把新关卡数量当作调度器的旧契约。

## 实际攻击与反馈

- E-01：近战扇形命中，范围扇形默认隐藏，保留短暂挥击反馈。
- E-02：6m 内起手，锁定落点，8m/s 突扑，落地 1.6m 半径命中；黄线预警、运动线和落地反馈，能通过走位躲开。
- E-03：9m 内起手，0.8s 抛物线酸液，落地 2m 半径毒池，4s × 6 DPS；绿色落点、酸液团和拖尾、毒池气泡。已发射酸液独立于射手存活，碰撞场景实体，遮挡处不在墙后生成毒池。
- E-04：8m 内起手，6m/s 冲锋，路径命中一次；碰墙停止，显示路线和冲锋反馈。
- E-05：2.5m 内启动引信，1.5s 基础前摇，3.5m 爆炸范围，35 伤害并自毁；显示引信预警和冲击波。
- B-01：既有近战与场景延迟砸地保持，补砸地反馈。

一般攻击扇形仅由“调试范围”开关显示。设计需要玩家读懂的落点、冲锋路线、爆炸预警仍正常显示。反馈由模拟事实驱动，暂停冻结，渲染层不判定伤害。

当前美漫特效是投影到游戏画面的 Canvas ink，未实现 GPU 深度遮挡粒子或共享图集批次。旧 VFX 图集仍隔离，不能将它已存在称为已接入。冲锋击退/眩晕、爆炸对其他 NPC 的连锁伤害和专用动画仍待补齐，未在本次报告中宣称完成。

## 实际验证

- 33 个相关测试文件、649 项测试通过：含距离外禁止起手、令牌额度、种子复现、状态错开、独立瞄准、暂停释放输入、酸液持续伤害/躲避/障碍/射手死亡、突扑速度/落点、冲锋单次命中/墙阻挡、迁移与场景契约。
- `pnpm run typecheck`、`pnpm run editor:build`、`pnpm run content:check`、`pnpm run scene:check` 通过。构建仍有已有的大包警告。
- headed Chrome，HTTPS secure context，WebGPU adapter `nvidia / lovelace`，使用本分支独立 5200 服务与本会话标签页，未操作其他开发会话的 5100 服务。
- 实际鼠标点击画布：弹药 18→17，暂停后 firing=false。实际拖动左摇杆：玩家由 (3,0) 移至约 (3.708,0.161)；实际拖动右摇杆：弹药 18→17，松开/暂停后停止射击。
- 844×390 横屏英文布局可见；多指事件夹具用不同 pointerId，移动与 firing=true 同时成立，取消后 firing=false。该夹具临时替代指针捕获并恢复，仅验证状态隔离，不冒充手机硬件双指验收。
- 酸液视觉样例临时移除首波、注入一只 E-03 并提高玩家生命，用固定单步检查飞行、落地、持续伤害及暂停冻结。它是特效验收夹具，不是正常通关录像。随后重载恢复场景。

- Stop 后确认：资源账目 registered=3、disposed=3、pending=0，动态实例回落至0，作者场景 dirty=false、undoDepth=0。随后恢复第一层中文桌面预览，未保留临时高生命和调试刷怪。
- 开发者多指测试的第一次尝试使用了浏览器中不存在的 pointerId，产生两条 `setPointerCapture` 夹具错误；修正夹具后状态隔离通过，实际鼠标/摇杆路径无此异常。不能把这些历史夹具错误称作运行时零错误证据。

## 验收边界

游戏入口是 Editor Play 的独立游戏视图（URL `game=1`），未把 5101 的初始化样例改成完整发布宿主。未进行真实手机硬件、多机型输入、持续性能或完整三层平衡通关。第二层 48 个真实角色同屏 spot sample 约 28 FPS，不能声称达到 60 FPS；上游 retarget 的 partial 标记及接触校准警告仍存在。增加人群后，后续优化应针对动态蒙皮/动作解算与帧预算，并保留人群和攻击距离语义。
