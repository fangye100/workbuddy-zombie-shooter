### WU1：精确 Transform 命令与 Inspector/Gizmo 共用作者入口（F6、F2）

**写入 owner：** `packages/runtime/src/spawn-edit.ts` 及所属测试；`apps/editor/src` 下作者操作/变换适配模块、`ui.ts`、Gizmo 交互接线与相关测试。`main.ts` 仅保留必要装配接线。

1. Transform 命令保留修改前后三轴值，使 undo/redo 精确恢复原作者数据；保留已有外部 API 的兼容性，或同步所有调用者并补契约测试。
2. Inspector 与 Gizmo 通过同一个作者操作入口，以稳定 NodeId 更新文档、dirty、命令历史，再投影到 renderer。UI 不单独拥有一份可编辑真源。
3. 明确世界坐标/局部坐标以及父子变换转换；父节点变更时后代视图与作者数据一致。不要把渲染内部更新、Play 投影或 selection 更新自动记录成作者命令。
4. 输入手势按合理事务提交，避免每一帧一个 undo；校验失败恢复一致视图并给出 diagnostic。Play 期间沿用作者编辑禁用边界。
5. 本轮不要求 renderer 支持所有非均匀缩放显示，但必须无损保留原数据。移动/旋转不得顺带把三轴 scale 写成统一值；确实无法表示的操作须明确拒绝，不能静默破坏。

**验收：** [1,2,3] 缩放后撤销精确相等，redo 正确；仅移动/旋转不修改 scale；Inspector 与 Gizmo 的同一修改得到等价作者状态；父子局部/世界坐标一致；非法输入不污染文档/视图/历史；Play 期间没有作者写入。领域数值测试由 runtime owner 负责，交互及映射测试由 editor owner 负责。

### WU2：作者编辑可保存、重开可复现（F1）

**写入 owner：** 作者文档保存模块、`saveSpawnEditsInner` 接线、必要的 store 保存合同及对应 editor/devfs 测试。

### WU3：GUI/MCP 绑定保存共同保护（F3）

**写入 owner：** BindingSession/BindingDomain 保存合同、`tools/mcp-binding` 的 FsPort 与服务器适配、editor 绑定保存适配、devfs 或现有可复用文件写入 owner，以及相应测试。

1. 保存版本来自成功加载/显式 hydrate 时接受的内容，不能保存前才读取最新版本并拿它当旧版本。
2. GUI 与 MCP 的参与写入必须共享可保证 compare-and-write 的持久化机制。两个独立进程各自排队不能解决跨进程竞争；“先检查 hash，再裸 write”也不是原子保护。
3. 优先复用已有机制；若增加共同文件锁/协调适配，明确边界、失败释放和参与写入者。保留 MCP 的无头/离线使用能力，不把“必须先打开 Editor 页面”变成保存前提。
4. 过期会话显式 conflict，保留其本地修改；重新加载/接受最新版本后才能再次提交。冲突响应包含可供 GUI/Agent 定位的信息，不自动丢弃或强行覆盖。
5. 保存仅合并本域拥有的数据，保留 sidecar 其他合法字段。保证正常写入、冲突、I/O 失败时不会落下损坏 JSON。说明外部不遵守协议的直接文件写入不在锁保证内，不夸大保证。

**验收：** 两会话顺序 stale 写入，GUI/MCP 适配间真实并发竞争，成功更新 baseline 后再次保存，冲突时修改保留，无关 meta 保留，写入失败恢复。不能只测各自的内存队列或 mock 掉竞争窗口。临时复制资产运行真实 stdio MCP 验证，不改生产角色 sidecar。

## 6. 新会话的三子代理执行方式

用户显式指定 `queue-dev-3-subagents`。入口为 `C:/Users/fangy/.codex/skills/queue-dev-3-subagents/SKILL.md`，并遵守其 execution、角色合同与 `mode-6-1.md`。模式为 GPT-6.1，主会话 GPT-6.1 Sol / High / Fast。

| 角色 | 模型与 effort | 职责 |
| --- | --- | --- |
| Main | gpt-6.1-sol / high | 排队、派发、版本固定、证据与终审收口，不写生产/测试代码 |
| Audit/Test | gpt-6-luna / high | 有界勘察与里程碑实操；不改源码/测试、不提交 |
| Worker | gpt-6.1-sol / high | 唯一生产/测试 writer，连续执行整个队列并精确提交 |
| Final Reviewer | gpt-6.1-sol / high | 开发与必要验证结束后才创建，独立审查完整交付 |

三个子代理都使用 `fork_turns: none`，显式 model/effort，按阶段初始化并返回 READY；不是开三个独立开发会话。Main 核对宿主可观测配置，不用子代理自报替代实际模型证据。型号不可用时按 Skill 报 MODEL_UNAVAILABLE，不擅自换型。

Main 将本文完整交付给 Worker，说明所有后续 WU 及共享工作树约束；Audit 只获当前所需范围；Final Reviewer 获原始计划、base/final、完整 diff、提交和原始验证结果，不灌入“已经正确”的开发结论。共享工作树实操/终审时 Worker 停止写入。确认的原范围问题回灌原 Worker 追加修复，再审精确新 target。

Fast 由宿主会话设置控制，不能靠提示词实现；启动开发前由创建方核对。用户要求针对新主会话开启 Fast，不自动修改全局配置或其他会话。
