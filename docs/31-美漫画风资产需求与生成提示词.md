# 美漫画风资产需求与生成提示词

版本：2026-10-05 / v1。用途：交给 WorkBuddy 分项调用 Hunyuan 生成资产，再交回本项目做清理、LOD、图集装配和实景验收。本文是采购/生成需求，不改变已生效的场景、道具或武器玩法真源。

## 1. 本次补什么，先生成什么

需要补充中景与远景。现有程序化街区用于填补空白、提供轮廓和遮挡；目前缺少连贯的建筑造型、屋顶层次、具有故事性的立面和手绘材质。当前俯视相机看得到大量屋顶和地面，因此不能只做一张漂亮的正立面。

已核对 `assets/environment/props.json` 与当前交付报告：38 个既有环境资产已有 LOD1/LOD2，涵盖油桶、路障、车辆、便利店、加油站、仓库、地铁、医疗道具。**保留并复用这些资产，不在本批重复生成。** 新 ID 不占用已有 P-xx、S-xx 或角色 ID。

美术依据：用户提供的 [Ardot gameplay 设计稿](https://ardot.tencent.com/file/720788949675822?node_id=2%3A74) 的美漫画风与颜色语言；关卡结构和俯视视角仍以项目 GDD 为准。不同关卡可换建筑、气氛和危险类型，线条、材质笔触、阴影语言保持统一。

**第一批 P0，先形成第一层质量样板：**

1. `ENV-MID-01` 红砖公寓街段，`ENV-MID-02` 转角街楼，`ENV-MID-03` 汽修街段。
2. `ENV-FAR-01` 低层城市轮廓，`ENV-FAR-02` 工业远景。
3. `SKY-01` 无太阳的美漫天空全景。
4. `VFX-ATLAS-01` 战斗/环境美漫图集。
5. `WPN-01` 玩家手枪。

共 **8 项交付**。先用 MID-01、FAR-01、WPN-01 各一件和图集的一组效果校准画风，再批量生成其余项。不要一次生成一整座城市或把整张清单放进同一个 3D 网格。

## 2. 所有 3D 模型共用的生成要求

把下面这段与单件资产的描述一起作为 prompt；同时附 Ardot 的局部美术参考，避免把界面按钮也生成到模型上：

> 为第三人称俯视的末日僵尸游戏生成单件可复用 3D 资产。美式漫画、手绘色块、两至三档明暗、清晰有力的轮廓、适量粗黑结构线，暖灰米白的亮面、冷蓝灰与灰紫阴影，锈红或褪色橙作少量强调色。磨损应是有组织的大色块、接缝和少量裂痕，不要全表面密集黑色划痕或摄影扫描噪点。顶部与侧面同样完整，俯视时轮廓清楚。结构合理，独立物体，不带地台、地面、背景、人物、UI、文字、水印或品牌标志。不要烘焙太阳、投射阴影、泛光、景深或雾；可以有轻微接缝 AO。使用贴图表现小细节，不要用无数碎面表现污渍。不要添加双层外扩描边壳，最终外轮廓由游戏渲染器处理。

制作/交付规范：

- 尺寸单位为米。环境表采用 **W×D×H = X×Z×Y**，不是 GLB 向量顺序；Y 向上，正面朝 +Z，底部中心原点在地面 y=0。武器单独使用下文的局部坐标约定。
- “面数”全部指**三角形数量**，不是四边形或顶点数。表中是清理后的运行时 LOD0/LOD1/LOD2 目标上限，不是声称生成模型会准确遵守面数。
- 若 Hunyuan 不能直接控制拓扑、面数、UV 或物理尺寸，先交保留纹理的高质量源 GLB，附真实参数；由接入流程统一处理。不要仅修改文件名把高模冒充 LOD。
- 目标网格：外表面连续，合理硬边，无漂浮碎片/重叠壳/翻面，不能把门窗细节熔成波浪。远景可以是无内部结构的外壳，但所有可见方向和屋顶必须完整。
- 基础交付为 GLB + BaseColor PNG + 预览图。环境每件优先 **1 个材质、1 张 BaseColor**，baseColorFactor 白色 [1,1,1,1]。正常不透明，玻璃做深色不透明色块；暂不依赖透明窗户、PBR 特殊扩展或独立法线贴图才能看懂。
- 可额外保留 roughness/normal 源图，但当前这一批的可见品质必须在 BaseColor + 当前 toon shader 下成立。中景主件 BaseColor 2048²，远景 1024²，武器 1024²；源图可更高，运行时不默认全上 4K。
- 俯视约 52° 下的屋顶、女儿墙、雨棚、体块退台必须可辨。轮廓细节优先于密密麻麻的砖缝；远处不要画同样粗重的黑线。
- 建筑模块接缝按 2 m 栅格设计；表中的尺寸是整体包围盒，雨棚、楼梯等凸出物必须包含在尺寸内。门窗不需要可进入内饰。
- 参考预览：正面、背面、侧面、顶部、俯视 3/4 各一张。**用于图生 3D 的参考图只放单件单视角，不做多视图拼图**；多视图仅用于对照和验收。

## 3. Environment：中景与远景清单

下面每项的“描述”可直接接在通用 prompt 后。建议视距是摆放参考，不是新增玩法规则；游戏运行时仍以投影尺寸和场景相机验收。

### ENV-MID-01 — 红砖公寓街段 / P0

- **尺寸**：16×8×13 m；运行时三角形 LOD0/1/2：**12,000 / 6,000 / 2,000**；BaseColor 2048²。
- **美术描述**：三到四层旧红砖公寓，由两个相连但屋顶高低不同的楼体组成。褪色砖红墙、米灰窗框、深蓝灰玻璃，少量窗洞用木板封住；一个褪色青绿遮雨篷，局部水渍形成向下的大块笔触。没有文字招牌，留一块可后贴图的空白牌面。整体保留完整可读的城市住宅秩序，不是全毁废墟。
- **几何特征**：平屋顶、女儿墙、可读的烟囱与一个屋顶通风盒；窗台有真实浅凸出，砖纹与细裂纹只在贴图。带一段简化防火梯，台阶用连续楔面或少量踏板，不生成密集金属网。
- **用途/边界**：第一层道路中景，建议 15–40 m；侧背面完整便于复用，替换平板背景的主力，不加入内部房间或碰撞逻辑。

### ENV-MID-02 — L 形转角街楼 / P0

- **尺寸**：12×12×15 m；LOD **14,000 / 7,000 / 2,500**；2048²。
- **美术描述**：一幢有年代感的灰米色转角街楼，下两层有拱形门洞或封闭店面，上层为规则窄窗；转角立柱与破损檐口构成标志轮廓，局部酒红色遮阳篷，暗紫灰阴影。不要现代玻璃幕墙或干净商业综合体。
- **几何特征**：两个临街面形成 90° 转角；斜切角入口、两级退台屋顶、粗壮檐口。大破损限于一角，不把整幢楼打散。地面和道路不打包进资产。
- **用途**：第一层街口与关卡边缘构图，填补直线街段之间的断口；不是重新生成已有 S-02 便利店。

- **几何特征**：不同高度的低屋顶、清楚的门框、宽雨棚、一个侧排风箱。卷帘门波纹与小铆钉用贴图，雨棚有真实厚度。

## 4. VFX：一张共享美漫效果图集

### VFX-ATLAS-01 交付规格

- **一张 4096×4096 RGBA PNG，8×8 等分，共 64 格，每格 512×512。**
- 每格中心可用内容 480×480，四边留 16 px 保护带；图案不跨格。透明 alpha 背景，禁止画棋盘格、白底、网格线、序号、文字标签或水印。
- 建议实际制作先分效果生成高质量单帧/序列，再按固定坐标拼成一张图集。直接让模型画整张图集也必须复核格子对齐、透明度及逐帧连贯性；模型不保证精确 UV 排版。
- 统一不规则黑色墨线、暖白核心、橙黄爆闪、灰紫烟团、青色能量、黄绿腐蚀。两至三档色块，粗形状、少量网点；不要摄影火焰、真实体积烟、密集柔光毛边、背景光晕或过曝白色方块。
- 源图使用 straight alpha；透明像素的 RGB 做邻近颜色外扩，alpha 保持透明。接入时统一预乘或直通的混合约定，不能两边重复预乘。
- 资产图集属于共享纹理；场景发射器、位置、强度、持续时间及玩法半径必须存场景/行为参数。运行时瞬时反馈消费真实开火/命中事件，不生成假的伤害或暴击提示。

### UV 与运行时约定

配套机器可读文件：[comic-vfx-atlas-v1.json](art/comic-vfx-atlas-v1.json)，列出每个 ID、帧索引、像素内容矩形、UV offset/scale、锚点和建议时长。

```text
column = frameIndex % 8
row = floor(frameIndex / 8)
offset = ((column*512+16)/4096, (row*512+16)/4096)
scale = (480/4096, 480/4096)
atlasUV = offset + localUV * scale
```

这里 localUV=(0,0) 指内容左上，(1,1) 指内容右下；接入时对齐 WebGPU 上传与网格 UV 朝向，只在一处处理 Y 翻转。帧索引与 UV 数据属于资产元数据，不在场景中重复拷贝 64 份。

共享纹理能减少纹理绑定/资源重复，**不等于自动只需一次绘制**。后续 VFX renderer 应按同材质、混合和深度规则做实例批次：

- 漫画烟、爆闪主体：有黑边，使用一致的 alpha 混合；不能整个图集都走 additive，否则黑线会消失。
- 纯高亮火花/电弧可额外走 additive 批次；贴地/贴墙 decal 另用深度偏移或 decal pass；HUD 爆点又是另一层。
- 每实例数据：position、size、rotation、frameIndex、tint、opacity。先以可见特效不超过 128 个为工程预算，真实 GPU 测量后调整，不承诺尚未实测的 FPS。
- 4096² RGBA8 基础显存 64 MiB，完整 mip 链约 85.3 MiB；可做 2048² 运行时档，基础 16 MiB、完整 mip 约 21.3 MiB。GPU 压缩支持需另外验证。
- 4096 版 16 px 保护边配合图集采样 LOD 上限 4；缩成 2048 后保护边 8 px，相应限制为 3。生成各级 mip 时保持格子隔离并验收透明边，避免远处采样串格。
- 不把长寿命环境烟雾和巨幅天空塞满屏幕；透明覆盖面积/overdraw 仍然要控制。
- **当前新图集和上述批处理尚未接入。** 现有 Canvas 漫画反馈可先提供视觉参照，收到图集后再换成共享纹理实例渲染。

### SKY-01 — 美漫天空全景 / P0

- **类型/尺寸**：2D 等距柱状全景，4096×2048，sRGB，无 alpha；输出 PNG。它不是一个复杂 3D 模型，天空球由运行时几何承载。
- **Prompt**：末日美漫城市上空，顶部灰蓝、靠近地平线变成暖灰米色，几层宽而平缓的灰紫云团，云边以手绘块面和局部断线呈现；克制颗粒、少量网点，不是写实摄影，不是奇幻星空。360° 水平方向无缝，极区连续，无太阳、月亮、建筑、山脉、地面、文字或UI。下半球为低对比地平线延伸色，不画第二片城市。

- **验收**：贴球后检查左右接缝和极点；普通 2:1 横幅不等于合格的等距柱状全景。若生成器不能输出完整全景，交云带单图，由接入阶段做映射和接缝修复，不能宣称已无缝。

3. 第一层现为 **64 个静态 mesh，上限已满**。新背景通过替换现有背景、离线合并同材质街段或精简冗余对象接入；不能把每扇窗、每个楼体拆成新场景对象硬塞进去。合并是接入处理，不要求模型一次生成整座不可拆城市。
