# M2 敌人与地面 VFX：实现、编辑与验证

日期：2026-10-19。开发基线 `7b9b98bf8a80b5219a9ccc66bed617cd020646d8`；当前生产与场景验证快照 `4b67359`。本文记录 Worker 开发证据，独立 Audit 与 Final Reviewer 尚待 Main 调度；不提前写成验收批准。[原 proposal](vfx-system-proposal-20261019.md) 和 [M1 历史交付](vfx-m1-20261019.md) 保留各自版本属性。

## 职责与真源

[scene/vfx.ts](../../packages/scene/src/vfx.ts) 提供资源 v2 和通用 `VfxBindings`：opaque tag → GUID/path + effectKey。Framework 不识别酸液、突扑等游戏标签；标签语义与转换都由 [EnemyVfxPlanner](../../packages/zombie-game/src/presentation/enemy-vfx-planner.ts) 持有。scene schema 为 v16，15→16 显式迁移不凭空加入绑定；原场景只升级版本，未绑定时沿用 Canvas。

场景当前只允许一份 enabled VfxBindings；重复组件报 `E_VFX_BINDINGS_DUP`。通用 resolver 还防御性排除重复 tag 并报告所有冲突 NodeId，不按节点遍历顺序静默覆盖。绑定引用进入资源遍历、移动/重命名和真实文件门禁。

[EnemyAttacks](../../packages/zombie-game/src/enemy-attacks.ts) 继续拥有攻击轨迹、阶段、半径、伤害和结束。新增 runId/attack id/sequence、phaseTick/finishTick、不可变 spawn/phase/impact/end 快照；接触点与 surface 不再回查后续槽位。事件队列上限 2048，溢出计数可观察；同一渲染帧跨多个模拟 tick 仍消费落地/结束。酸液已发射后按原规则独立飞行，发射者死亡或槽复用不改变快照；blocked 酸液不生成 pool；自爆在自杀前记录快照；突扑使用实际 move 返回的 finished 点。本阶段不改变伤害、攻击时序或碰撞规则。

[runtime/vfx.ts](../../packages/runtime/src/vfx.ts) 的稳定 upsert/stop 句柄只管理表现。持续酸液位置跟随真实 fact，pool 直径严格为 `2 * radius`，remaining/结束来自模拟；asset duration 是动画周期或装饰尾部，不能延长危险。装饰灰色痕迹独立 TTL，不画结束后的绿色危险环。

## 资源与 GPU

[comic-enemies.vfx.json](../../assets/vfx/comic-enemies.vfx.json) 是正式 accepted v2 资源，使用五张本任务原创透明 SVG：酸滴、酸池、爆闪、突扑冲击、灰色地面痕迹；多帧资源有独立形变。未启用旧隔离图集，也未采用未跟踪交付。7 个游戏绑定覆盖 flight/land/pool/blocked/explode/pounce/mark，复用 M1 单一 Pass 和有界 256 实例池。

VFX v2 添加通用 `sprite`、camera/surface 朝向及循环帧。v1 显式兼容：编辑值迁移为 v2，impact 默认 surface 保留 M1 法线对齐，其余 camera；原始磁盘对象单独保留作 CAS 基准，保存才升级文件。编辑面板、Play 诊断与门禁均显示 v1 兼容状态，未来版本拒绝。正式手枪资源仍保持原 v1。

[VfxPass](../../packages/render/src/vfx-pass.ts) 在 scene 后、post 前 load 原 HDR/aux/depth，深度测试 less-equal、关闭深度写入。surface 使用真实法线构造平面并沿法线偏移 0.008m；camera 显式覆盖 normal，缺 surface 锚点时判定不可绘制。Alpha 按相机深度远到近，再合批连续兼容实例；纹理 sRGB、shader 线性 tint/预乘 alpha，覆盖像素按 `(1-alpha)` 衰减 aux.a，透明像素 discard 保留原描边。

[PlayVfx](../../apps/editor/src/services/play-vfx.ts) 以 PlaySession 注册真实资源，Stop/重开关闭旧 generation，异步旧纹理解码不会复活资源。当前完整 M2 场景有 2 buffers、8 textures（含 M1 三张）；Stop 实际逐个 destroy。纹理预算 16 张/4096px，实例 256；加载失败、坏 key、缺 surface、纹理预算或池预算失败均留诊断/overflow/fallback 统计。Canvas 按每 attack handle 的实际 drawable 成功判定替换，酸池真实半径轮廓独立保留，不依赖纹理或 GPU 实例预算；windup/range 提示继续读取模拟。

## 产品入口与持久化

固定 HTTPS 5100、原 dev server，正式注册入口：

| 场景 URL 的 scene 参数 | 用途 |
| --- | --- |
| `assets/scenes/sandbox/vfx-m2-acid.scene.json` | 真实 E-03 flight→land→pool→end |
| `assets/scenes/sandbox/vfx-m2-acid-blocked.scene.json` | 高墙拦截酸液，无 pool |
| `assets/scenes/sandbox/vfx-m2-pounce.scene.json` | 真实 E-02 突扑 actual finished 点 |
| `assets/scenes/sandbox/vfx-m2-explode.scene.json` | 真实 E-05 自爆与死亡后快照 |

每场景有 PlayerStart/RunRules/NavZone、真实墙柱 Collider、场景地面和独立攻击者；interact 条件保留未清关状态，自爆者死亡后模拟仍推进。不需要 damage/teleport/strike 调试钩子，点击 Play 后由原 NPC 状态机自然发起攻击。扑击场景地面只有可见 mesh；其 surface NodeId=null 表示既有模拟地平面 `[0,1,0]` 法线，不能当作 Collider 接收者。酸液场景落地确实记录 `nd_vfx_ground`。地面以下 Collider 在现有导航中仍会投影为 XZ 障碍，因此未为扑击 fixture 增加整块地面 Collider，也未扩修该既有导航语义。

1. 右侧 Inspector「场景」页 →「场景 VFX · 通用标签绑定」：输入 opaque 标签，选择「绑定资源」→「读取绑定资源」→「效果 key」→「应用标签绑定」。可「移除标签绑定」「撤销标签绑定」「重做标签绑定」「保存标签场景」。绑定在场景历史和场景 CAS 保存中，整页 reload 从磁盘恢复。
2. 相邻原 VFX 资源面板保留 M1 武器绑定，资源选择支持 `comic-enemies.vfx.json`；「编辑效果」可调宽高、颜色、持续时间、camera/surface 朝向和循环帧，Apply/Undo/Redo。危险区尺寸与结束显示跟随模拟，不用资源参数覆盖。
3. 「循环 GPU 预览」默认当前效果，可选完整资源；surface 预览只用起点下方真实 Collider 点/法线，缺少接收面显示诊断。预览只读场景，停止销毁 GPU 资源。
4. 「保存 VFX 资产」「重载 VFX 资产」独立于场景 dirty；CAS 冲突保留草稿并提示外部修改，显式 Reload 才采用磁盘对象。坏资源显示错误并保留已加载资源。
5. Play 后同面板「play」统计展示 enemy ready/rendered、事实事件、instance 位置/尺寸/age/lifetime（可推 remaining）、fallback/eventDrops、pool dropped、GPU draws/upload/textures 和 Stop lastReleased。

保存验收只改 `.workbuddy/tmp/vfx-m2/` 副本。受控探针在自己测试标签页的 aether.project.json 响应里投影登记副本，磁盘项目不改，产品 loader/写盘边界不放宽。不存在任务专用产品按钮或 query 后门。

## 开发实证与范围

M1 回归在 `1a0ab38` 为 23/23，通过 v1 编辑→v2 保存/CAS、三件套实际射击、真实 NPC contact、遮挡和 Stop。最初一轮受新增资源改变目录排序影响，探针误选了第一项；已改为用产品路径显式选择手枪资源并完整重跑，失败轮保留为 m1-regression，不计通过。

M2 早期 development-01 的真实墙 aux 基线全零，无法证明衰减；后续只在验证工具中输入受控 aux=1 并读回。development-final 的 CAS 断言遇到异步 Reload 尚未完成，development-final-2 在启动装配完成前取控件；已改为等实际资源 Reload 状态/面板可用。早期扑击落点被地面 Collider 推到导航边缘，事实/实例虽一致但不满足可见验收，因此只修 fixture 并补位置和可见像素断言。所有失败轮保留，最终结果见下列快照。

本阶段没有持续发射器、烟火/冲锋拖尾、compute、跨面 projector/DBuffer、节点图或通用 profiler；M3/M4 继续按 proposal 另行推进。surface 仅明确平面 quad，不认证跨面贴花。当前成本和视觉只覆盖本机 NVIDIA Lovelace 轻量 fixture，不外推手机或大并发。

最终 Worker 受控结果 `.workbuddy/tmp/vfx-m2/development-ready/result.json`：生产/场景快照 `4b673596`，工具源码另存 SHA-256；**36/36 通过**。secure context=true、isFallbackAdapter=false、NVIDIA Lovelace，console/GPU 错误和未捕获异常为空。酸液 start tick60、pool tick84（真实落点 `[0,0,0]`，receiver `nd_vfx_ground`，半径2m、GPU直径4m）、end tick204 后连续危险实例撤销；装饰痕迹独立到期。突扑实际 finished 点 `[0,0,0]` 与锁定目标重合，radius1.6m、GPU尺寸3.2m；surface NodeId=null 为模拟地平面，真实扣血18。`06-pounce.png` 已目检有可见冲击图形，暂停原事实/相机只切换已有 GPU Pass on/off，200×140 ROI 中 13383 像素差异>8，超过至少15的门槛。自爆半径3.5m、图形7m、实际伤害35，source死亡后快照仍保留；interact 未清关条件使真实 end 可继续观察。

平面隔离证据使用同一酸池纹理/normal/0.8m方形、暂停相机 eye `[-3.884871,9.192388,8.331133]`，墙中心 `[4,1,4]` 沿视线前后1.2m，100×100 ROI、RGB差异>8：墙前2966像素、墙后0；预设前至少15/后最多2。显式 camera/surface 朝向切换3208像素；近远输入顺序反转0、互换近远颜色2875，验证实际深度排序而非输入顺序。独立受控 aux=1 输入后直接GPU compute textureLoad读回：覆盖区2498样本降低、5959样本不变、真实遮挡后0变化；所有验证读回 buffers 在 finally destroy。该 aux 输入仅验证覆盖/透明合成，不声称原墙材质本身具有非零mask。原始相机、点、阈值和逐模式PNG均在同目录。

满池验证只向表现池输入256个高优先级装饰实例，不改模拟事实：active=256、dropped=4，真实危险 handle 失去 drawable 时 fallback>0、rendered不包含该attack，独立真实半径轮廓与Canvas保底仍可见。坏effect key则显示带tag/key诊断并保留原表现。5次 Play→Stop（含坏binding）每次账目 registered=4/disposed=4/pending=0，实际销毁2 buffers/8 textures；受控Chrome已关闭，5100服务保留。新酸滴、池、爆闪、突扑已按真实GPU截图目检；灰色痕迹的创建/到期由真实实例检查覆盖，未单独作无遮挡美术放大验收。资源是本次最小正式美术，未认证更复杂特效品质。酸液 end 截图仍可能出现下一轮真实 windup 预警轮廓，不能把该新攻击提示误读为已结束 pool 的残留。
