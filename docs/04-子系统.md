# L4/L5 — 场景与子系统

统一约定：每个子系统以 `Plugin` 形式挂载，暴露 `build(app: App)`；通过 `Stage` 注册系统，
通过 `Resource<T>`（全局单例）与 `Event<T>` 通信。禁止横向直接引用。

---

## 1. ECS 核心（core/ecs）

**Archetype + SoA**，组件以 `TypedArray` 存储。

```ts
// 组件定义（编译期生成 id 与反射信息）
const Position = defineComponent({ x: f32, y: f32, z: f32 });
const Velocity = defineComponent({ x: f32, y: f32, z: f32 });

world.spawn().add(Position).add(Velocity);
world.query([Position, Velocity]).forEach((ent, pos, vel) => { /* ... */ });
```

### 关键机制

| 机制 | 说明 |
|---|---|
| **Archetype** | 相同组件集合的实体共享一张表；组件数据按列存 `Float32Array`，cache 友好 |
| **Entity 句柄** | `u32 index + u24 generation`，检测 use-after-free |
| **CommandBuffer** | `spawn/despawn/add/remove` 延迟执行，在 Stage 边界同步点批量应用（避免迭代中改结构） |
| **变更检测** | 每次写入标记 `ChangedTicks`；查询支持 `Changed<T>()` / `Added<T>()` 过滤 |
| **调度** | 系统声明 `reads/writes`，调度器做冲突检测 → DAG → 并行 |
| **关系** | 父子层级用 `Children`/`Parent` 组件，层级传播按层并行 |
| **序列化** | 反射信息自动生成二进制 schema，版本化（含 migration 钩子） |

**性能红线**：单帧实体增删 > 1000 时用批量 API；热路径查询用 `for (const [a,b] of q.iter())`
（迭代器复用，零分配）。

## 2. 场景与变换（scene）

- **Transform**：`LocalTransform(translation, rotation, scale)` + `GlobalTransform(Mat3x4)`。
- **双缓冲**：保留上一帧 `GlobalTransform`，渲染插值用（见主循环第 4 步）。
- **层级传播**：按深度分层，层内并行（`PropagateTransformSystem`）。
- **Prefab**：YAML 源（可 diff / 可读）+ 二进制运行时（`.prefab`）。实例化走 **copy-on-write**，
  未覆盖字段共享原型数据。
- **SubScene / 流式加载**：场景按空间分块（UniformGrid / Octree），
  按相机距离 + 预测（`camera velocity`）异步加载/卸载，加载在 Worker，解码后上传 GPU。
- **LOD**：`LodGroup` 组件（屏幕空间误差 SSE 或距离阈值），切换带 **cross-fade dither** 防跳变。

## 3. 资产系统（assets）

```
源资产 (glTF / FBX / PNG / WAV / .material)
   │  tools/baker（Node CLI，离线）
   ▼
运行时格式 (.mesh / .tex.ktx2 / .anim / .pak)，全部 mmap 友好、零拷贝可解
   │  AssetServer（Worker 中解码）
   ▼
GpuResource（上传走 StagingRing）
```

| 项 | 设计 |
|---|---|
| **标识** | 内容寻址 `AssetId = blake3(content)`，天然去重与增量更新 |
| **打包** | `.pak` = 索引表 + 数据块（对齐 4KB），支持 **范围请求**（HTTP Range）按需拉取 |
| **网格** | `.mesh`：顶点/索引分离，meshopt 编码（量化 + index compression），含 **meshlet** 数据（128 tri / 64 vert 上限，含 cone bounds） |
| **纹理** | KTX2 + Basis，按设备能力选择 BC7 / ETC2 / ASTC / 未压缩 |
| **句柄** | `Handle<T>` 带强/弱引用计数；`AssetEvent::Loaded/Modified/Removed` 驱动热重载 |
| **生命周期** | LRU + 引用计数；卸载有 **延迟宽限**（2s）防止抖动 |
| **热重载** | 监听 `Modified` 事件，在帧尾安全点替换 GPU 资源（in-flight 帧不受影响） |

## 4. 动画（animation）

- **骨骼**：`Skeleton`（层级 + inverse bind matrix），`BoneMatrix` 存 `StorageSoA`。
- **蒙皮**：**compute skinning**（顶点着色器不动，compute 输出 skinned vertex buffer，
  可被深度 prepass / 阴影 / 主光栅**复用**，避免重复计算 3 次）。
- **动画图**：
  ```
  StateMachine / BlendTree(1D, 2D) / Layer(override-additive) / IK(TwoBone, FABRIK, LookAt) / Morph
  ```
- **采样**：fixed-step 采样 → `PoseSoA`（每个骨骼的 T/R/S），随后 blend → 本地矩阵 → 全局矩阵。
- **根运动**：`RootMotion` 提取后交给角色控制器（物理移动），而非直接写 Transform。
- **LOD**：远处角色降频（30Hz）、跳过 IK、跳过次级骨骼。

## 5. 物理（physics）

**后端 Rapier (Rust→WASM SIMD)**，引擎只做适配层。

| 层 | 内容 |
|---|---|
| 组件 | `RigidBody / Collider(Shape) / CharacterController / Joint / Raycast` |
| 同步 | `SyncToPhysics`（逻辑→物理）→ `step` → `SyncFromPhysics`（物理→逻辑），只在 fixed 步长执行 |
| 插值 | 物理结果写入 `prev/curr`，渲染插值，避免 60Hz 物理在 144Hz 屏幕上抖动 |
| 查询 | `Raycast / Shapecast / Overlap`，走空间加速结构；结果打包为 Job 批量执行 |
| 调试 | 碰撞体线框渲染 pass（复用 debug draw buffer） |
| 确定性 | 固定步长 + 固定迭代次数 + 禁用随机；用于网络回滚 |

**子步**：`step(dt)` 内部按 `maxSubsteps` 细分，防止高速穿透；CCD 只对标记对象开启。

## 6. VFX / 粒子（vfx）

- **GPU 粒子**：位置/速度/生命/属性存 storage buffer，compute 更新，**`drawIndexedIndirect` 渲染**，
  CPU 零参与。容量上限按 pool 预分配（如 100 万）。
- **图化特效**：`VfxGraph`（节点：Spawn / Init / Update / Render），编译为
  **一组 compute + render 指令**（避免运行时解释开销），UI 可视化编辑。
- **类型**：Sprite / Mesh / Ribbon(拖尾) / Beam / Decal / GPU 事件（碰撞、死亡）回读。
- **排序与混合**：粒子走 OIT 或按 tile 排序；软粒子（深度淡出）用深度缓冲采样。
- **预算控制**：全局粒子预算，超出时按优先级降低 spawn rate（Adaptive Quality 联动）。

## 7. UI（ui）

**保留模式 + GPU 批渲染**，不用 DOM。

- **布局**：Flexbox 子集（`yoga` 或自研），增量布局（脏节点向上传播）。
- **渲染**：所有图元合批到少数几个 draw call；
  图集 + SDF 文字（MSDF 更锐利）+ 9-slice + 圆角/阴影（SDF 距离场）。
- **输入**：焦点链、命中测试（空间哈希）、拖拽、键盘导航、无障碍（语义树 → ARIA 镜像 DOM）。
- **特性**：分辨率无关（DPR）、主题/样式表、过渡动画、世界空间 UI（3D HUD）。
- **文字**：字体图集动态栅格化（glyph cache）+ 整形（复杂脚本用 HarfBuzz WASM）。

---

## 8. 音频（audio）

- WebAudio 图：`Source → Bus(SFX/Music/Voice) → Master → DynamicsCompressor → Destination`。
- **3D 空间化**：`PannerNode`（HRTF）或自研 HRTF convolution；距离衰减 + 遮挡（射线检测）。
- **流式**：音乐用 `AudioWorklet` + 环形缓冲解码，避免整文件入内存。
- **池化**：并发声源上限（如 64），超出的按优先级抢占（voice stealing）。
- **总线快照**：`Snapshot`（如"水下"低通滤波）可平滑过渡。
- **注意**：AudioContext 需用户手势解锁，引擎提供 `audio.unlock()` 一次性处理。

---

## 9. 输入（input）

- 设备：键盘 / 鼠标 / 触摸 / 游戏手柄 / 陀螺仪 / 笔。
- **Action Mapping**：`Action("jump")` ← 多绑定（Space / 手柄 A / 屏幕按钮），
  支持运行时重绑定 + 配置持久化。
- **边缘检测**：`pressed / justPressed / justReleased`，以及 `Axis1D / Axis2D`（带死区、曲线）。
- **指针锁 / 相对模式**：FPS 场景必需。
- **事件模型**：输入在帧首采样为快照，系统读快照（而非回调），保证逻辑确定性。

---

## 10. 脚本（script）

- **主方案 TypeScript 原生**：`ScriptComponent` 持有脚本实例，
  `onStart / onFixedUpdate / onUpdate / onDestroy`，通过 Vite HMR 热替换
  （保留实例状态：序列化 → 换类 → 反序列化）。
- **沙箱方案（UGC / Mod）**：QuickJS-WASM 运行 Lua/JS，受限 API、超时与内存配额。
- **生命周期安全**：脚本内 `entity` 可能已被销毁 → 所有 API 走句柄 + generation 校验。

---

## 11. 网络（net）

| 模式 | 适用 |
|---|---|
| **锁步 + 回滚**（GGPO 风格） | 格斗 / RTS；需确定性 + 状态快照（每 8 帧一个 snapshot，回滚最多 8 帧） |
| **客户端预测 + 服务器校正** | FPS / 动作；本地立即响应，服务器权威状态到达时平滑纠正 |
| **状态同步（快照插值）** | MMO-lite / 观战；带宽优先，延迟容忍 |

- 传输：**WebTransport**（UDP，首选）/ WebSocket 回退。
- 序列化：位打包 + **delta 压缩**（基于上次确认的基线）。
- 兴趣管理：按空间格子分发，减少无关实体同步。

---

## 12. 大世界与地形（terrain）

- **地形**：Heightfield + **Clipmap**（geo-clipmap，GPU 顶点位移），或
  **虚拟纹理**驱动的 quadtree LOD。
- **植被/散布**：GPU 散布（密度图 → compute 生成 instance → HiZ 剔除），
  风动画在顶点着色器（噪声）。
- **虚拟纹理**：Page Table + Tile Atlas + feedback buffer（compute 读回，2 帧延迟容忍）。
- **世界分区**：格子化 SubScene + 关卡流 + 数据层（Data Layer）按需加载。
- **坐标精度**：大世界用 **Camera-Relative Rendering**（每帧把世界原点平移到相机附近），
  避免 float32 抖动。

---

## 13. 存档与序列化（save）

- **格式**：二进制，头部 `magic + version + schemaHash`；正文为 SoA 列式，便于增量。
- **迁移**：版本升级走 `migration: v1 → v2` 钩子链，保证旧存档可读。
- **写入**：IndexedDB（浏览器）/ 文件（Deno）；写前写临时块再原子替换，防损坏。
- **云存档**：可选 Connector，冲突用 last-write-wins + 时间戳。

## 14. 本地化（i18n）

- Key-based（`ui.menu.start`），ICU MessageFormat（复数、性别、日期/数字格式化）。
- 运行时切换语言，UI 自动 reflow；字体回退链（缺字时按脚本族回退）。

## 15. 剖析与调试（profiler）

| 工具 | 内容 |
|---|---|
| **CPU 时间线** | 每个 System / Job 的耗时，火焰图（自研轻量 UI，非 DOM） |
| **GPU 时间线** | timestamp query 每个 pass 的耗时（2 帧延迟读回） |
| **内存账本** | 显存按分配器分类、WASM 堆、JS 堆、资产缓存 |
| **实体/资源统计** | 实体数、archetype 数、draw call、三角形、光源、材质变体数 |
| **渲染调试视图** | wireframe / overdraw / lightCount / HiZ / 各 GBuffer 通道 / 剔除统计 |
| **控制台命令** | `r.Shadow.Cascades 2`、`r.Resolution 0.75`、`stat gpu`、`profile 300` |
| **录制回放** | 记录输入序列 + seed，重放用于复现 bug |

## 16. 子系统依赖矩阵

| 子系统 | 依赖 | 被依赖 | 主循环阶段 |
|---|---|---|---|
| input | platform | script, ui, camera | 帧首 1 |
| physics | core, scene | script, animation(根运动), vfx | FixedUpdate |
| animation | core, assets | render(extract) | FixedUpdate + Extract |
| vfx | core, gfx, assets | — | Variable + Render |
| ui | core, platform, render | — | Variable + Render |
| audio | platform, scene | — | Variable |
| net | core, platform | script, physics(回滚) | FixedUpdate |
| terrain | scene, assets, gfx | render | Extract |
| script | core, 全部（只读接口） | — | Fixed + Variable |
| profiler | 全部（旁路） | — | 帧首 + 帧尾 |

## 17. 插件与主循环挂载点一览

```ts
app.addPlugin(plugin)
   // plugin.build(app) 内部：
   .registerComponent(MyComponent)             // 反射注册
   .addResource(GpuStats, new GpuStats())      // 全局单例
   .addEvent(CollisionEvent)                   // 事件通道
   .addSystem(Stage.FixedUpdate, stepPhysics)
   .addSystem(Stage.Update,   updateCamera).after(stepPhysics)
   .addSystem(Stage.Extract,  extractRender).inSet(RenderSet)
   .addRenderFeature(MyFeature)                // L3 扩展
   .addAssetLoader(['gltf','glb'], GltfLoader) // 资产扩展
```
