### 🔴 环境侧判据（docs/06 §7.8 角色判据在此失效，实际采用）
- 否决：边界边 0 + 非流形 0 + 彩度落后**该件原生** ≤5~12pp + 面数 ≤ 预算×1.5
- 只记录：UV 密度（环境侧 1.5~22，判据 <3 不适用）、面积保持率（可 >100%）
- 面数**不设下限**：QEM 不保证精确命中预算，只卡上限
- 判彩度必须跟**自己原生**比，不是跟别人比（这是判别力实验的核心）

### 🔴 碎壳体（shelly mesh）新坑 —— P-05 / P-43 救不了
- P-43 轮椅 420 面预算但有 **6208 个连通壳**；P-05轮胎堆 320 面但有 **17255 个壳**
- 全局 QEM 按误差全局排序 → 优先把大壳减碎，小壳一个不动 → P-43 卡在 5186~5190 面
- P-05 减到 615 面时相邻壳被焊一起 → 边界 49 / 非流形 42
- **六组参数扫描（焊点阈值 0.0002/0.002/0.01 × UV 权重 1.0/0.3）全部失败** → 调参救不了
- 🔴 **预算物理不可达**：6208 壳 × 最低 4 面 = 24832 面 >> 420 预算。
  `props.json` 的 `tris` 按连通件估算，没考虑碎壳倍数 → **预算定档本身有问题**
- 正解（未做）：按壳分配面数预算 → 逐壳减面 → 合并。`try_shells.py` 已验证壳数分布

### 🔴 边数判据的实现坑：必须按位置去重，不能按顶点索引
