## ✅ P3 行为执行接线完成（commit 3837e99 → f36cbf6 → 05f121f，已推送）

### 架构要点（后续复用）
- **执行器端口** `packages/runtime/src/behavior-executor.ts`：runtime 只认 `BehaviorExecutor`
  接口，**不 import 行为代码**（R3）。`NULL_BEHAVIOR_EXECUTOR` 让"没接执行器"显式可见。
- **BehaviorContext = { tick, runId, log(message) }**。行为**不要** console.log：
  污染宿主日志、CLI/浏览器不一致、没法断言。log 落到 `session.behaviorLog`。
- 装载期收集：loader 收场景节点 Script（隐藏 → W_SCRIPT_HIDDEN；空 id → W_SCRIPT_EMPTY；
  **params 必须拷贝**，否则运行期改写污染作者文档）。
- 执行时机：`step()` 在 `moveNpcs()` 后、`tickCount++` 后调 `runScripts()`。
  行为看到的是**本步最终位置**，否则"是否进入某区域"会差一步。
- 🔴 **runtime 不信任执行器**：runScripts 里再包 try/catch，异常 → W_BEHAVIOR_THREW。
  行为是内容层（Agent 自由创作），抛异常是常态，不能把"不崩"寄托在注入方自觉上。
- behaviorLog 封顶 200 + reset 清空（跨代日志混进来会让"重跑了没"说不清）。
