## 诊断：关卡里的占位体为什么换不成真 NPC（三个缺口）

用户反馈「场景关卡里全都是 Proxi，怎么换成真正的 NPC」。调查结论：

- ✅ **模型是现成的**：assets/characters/models/ 下 E-01~E-05、B-01~B-03 齐全，
  每角色有 `rigged/*_rigged_animated.glb`（骨骼+动画，最适合 NPC）与 `textured/*_baked.glb`。
- ❌ **缺口 1：characterId → GLB 路径的映射不存在**。roster.json 有完整数值
  （hp/speed/attack/ai/silhouette…）但**没有 model 字段**；packages/content/src/generated/
  里也没有任何 glb 引用。
- ❌ **缺口 2：场景加载不支持 GLB 引用** —— `apps/editor/src/renderer.ts:803-806`
  对 `o.mesh === null`（asset 类型）直接 `continue` 并 warning
  「外部资产网格暂不支持在场景加载期同步取用，已跳过」。
  即：**就算在 .scene.json 里写了 GLB 路径也渲染不出来**。
- ❌ **缺口 3：prefab(S5) 与 Play/Spawn(S3) 都没做** → 「会动的 NPC」当前不可能。
- 背景：关卡里的方块/圆柱是 9/9 生成的 **gizmo 占位体**（instantiate 只认 MeshRenderer，
  语义节点必须挂几何代理才可见），不是错误数据。
- 最小可行路径：让 loadScene 异步加载 asset 网格（编辑器已有 parseGlb）+ 建 characterId→GLB
  映射（正路是 roster.json 加 model 字段走 content:gen；快路径是先在 gen-level.mjs 建映射表）。
  换完仍是**静态模型**，不会动；动起来要等 S3。
- 容量无风险：物件数不变（圆柱换模型仍是 18/64），只涨三角形（E-01 900 tris × 6）。

## 追问三连（用户）：分类依据 / 不改引擎做分类 / 运行时脚本

1. **「Game Editor 依据什么判断实体是 NPC」→ 现在没有任何判别机制。**
   - `category`（SceneNode.category）：document.ts 明写「纯展示，不影响渲染行为」；
     renderer.ts 只在 131/203/356 定义、423-497 赋硬编码值、729/819 透传，**零 if/switch 分支**。
     instantiate.ts 缺失时回落 '道具'。fallback 场景用过 环境/角色/道具/敌人 四类。
   - `layer`（MeshRenderer.layer / Collider.layer）：BUILTIN_LAYERS 8 个含 **Character（索引 5）**，
     但注释「引擎保留字段，当前 shader 未消费，先占位以免后期改 schema」。
   - `tags`：project.ts 定义了 `tags: string[]`（注释举例 Boss/Loot/Destructible），
     但 **SceneNode 上没有 tag 字段** —— 表建好了，节点没地方挂。
   - 真正有语义的只有 `SpawnPoint.characterId`（引用 roster 的 E-01/B-01），
     但它在 instantiateScene 被跳过（只认 MeshRenderer）→ **运行时无消费者**。
2. **「不改引擎做分类+自动化」→ 能到数据层，到不了行为层。**
   可做：category 约定（Hierarchy 已按它分组）/ layer 填 5（字段存在、填了不报错、等引擎消费那天自动生效）/
   生成脚本里做自动化（gen-level.mjs 就是这条路）。
   做不到：GLB 引用渲染（renderer.ts:803 硬跳过）、任何行为驱动（无注册表/无运行时/无 Play）。
3. **「运行时动态加载执行独立脚本组件」→ 不能，且架构明确禁止。**
   ADR-017 / agents.md §2.2 明令场景不得存代码字符串（JSON 携带可执行文本 = 远程代码执行入口）；
   设计是 Script 只存 `{behavior, params}`，行为本体是 `assets/behaviors/*.ts` + `defineBehavior` 注册。
   **实证：`assets/behaviors/` 目录不存在，`defineBehavior` 全仓只出现在注释与 docs/14 设计文档里，
   注册表/加载器/执行器零实现。** 让 NPC 动的正路 = 实现行为注册表 + Play 模式(S3)，不是运行时 eval。
